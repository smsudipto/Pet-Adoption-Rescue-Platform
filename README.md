# 🐾 Pet Adoption & Rescue Platform

A full-stack web application built with Django and Bootstrap 5 to connect rescue pets with loving families, featuring advanced filtering, user authentication, favorites, pagination, and a fully documented Django REST Framework (DRF) API.

---

## 🚀 Features

* **User Authentication & Authorization**: Secure registration, login, logout, and token-based API authentication.
* **Pet Categorization & Filtering**: Filter pets by animal type (Dog, Cat, Bird, Rabbit, Other), breed, gender, adoption status, and location.
* **Favorites System**: Authenticated users can add or remove pets to/from their personal favorites list.
* **Web Pagination**: Clean pagination interface on web templates for smooth navigation across large pet lists.
* **REST API with Pagination & Token Auth**: Endpoints powered by DRF with `PageNumberPagination` and Token-based security.
* **Responsive UI**: Designed using Bootstrap 5 for seamless mobile and desktop experiences.

---

## 🛠️ Tech Stack

* **Backend**: Python, Django, Django REST Framework (DRF)
* **Frontend**: HTML5, CSS3, Bootstrap 5, Django Templates
* **Database**: SQLite / PostgreSQL
* **Tools**: Git, GitHub, Postman
